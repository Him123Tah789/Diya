## 🌟 Highlights & Features

- **🌐 Dual Language Support (English 🇬🇧 & Norsk 🇳🇴)**: Instant toggle between English and Norwegian.
- **🎵 Synthesized Web Audio Engine**: Classic *Happy Birthday to You* chime melody + interactive SFX (balloon pops, candle blows, unbox fanfare, fireworks).
- **🎈 Mission 1: Balloon Pop Arcade**: Pop 5 balloons to collect Level 11 energy.
- **🎂 Mission 2: 11-Candle Cake & "Make a Wish"**: Blow out 11 flickering candles with smoke particles and send a shooting star across the cosmos.
- **🎁 Mission 3: Interactive Mystery Gift Box**: Unwraps and bursts away to reveal a special video greeting (`MicrosoftTeams-video.mp4`) with automatic audio ducking.
- **📸 Mission 4: 13-Photo Polaroid Memory Hall**: 13 interactive polaroid memories with hover tilts, captions, and high-res lightbox zoom.
- **💌 Mission 5: The Heartfelt Blessing & Custom Poster (Presented by Faishal)**: Full-width glowing poster card, sweet wish clouds, and dua from মামা.
- **🏆 Grand Finale: Level 11 Superstar Certificate & Screen Fireworks**: Tap anywhere on screen to launch rockets!

## 🚀 Live Demo & Deployment

### Run Locally:
1. Simply double-click `index.html` in any web browser.
2. Or serve locally with Python:
   ```bash
   python -m http.server 8080
   ```
   Then visit `http://localhost:8080`.

### Deploy to GitHub Pages (Free Hosting):
1. Go to your repository on GitHub: `https://github.com/Him123Tah789/Birthday-Wish`.
2. Click **Settings** > **Pages**.
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save**. Your website will be live in seconds at:
   `https://him123tah789.github.io/Birthday-Wish/`
