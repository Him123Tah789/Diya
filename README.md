# 🌻 Happy Birthday, Meow! 💜 — 19th Birthday Pikachu Edition ⚡

A magical, interactive 19th birthday celebration web experience featuring Pikachu, Pokémon friends, memory galleries, music, videos, a sunflower garden, and a full-screen 7-scene cinematic grand finale.

## ✨ Features
- **19th Birthday Milestone**: 19 wishes, 19 interactive candles on a 3D birthday cake, and mini-game challenge.
- **7-Scene Immersive Finale**:
  1. Dark violet Poké Ball reveal
  2. Golden electric flash explosion
  3. Interactive 3D birthday cake with 19 candles and 19 personalized wishes
  4. Pikachu surprise comic interrupt
  5. Mini-game: Help Pikachu collect 19 birthday hearts
  6. The golden gift box
  7. Grand reveal: Blooming sunflower, sky fireworks, the 19th Birthday Masterpiece Poster, and emotional blessings
- **Interactive Sunflower Garden**: Blooming sunflower interactive wishes.
- **Memory Galleries & Lightbox**: Full-resolution modal viewer with ambient backdrop blur.
- **Audio & Visual Effects**: Procedural canvas particle system (fireworks, stars, confetti, lightning) and Web Audio API synthesized chimes and fanfares.

## 🚀 Running Locally
Simply open `index.html` in any modern web browser, or start a local server:

```bash
python server.py 8000
```

Then navigate to: `http://localhost:8000`
